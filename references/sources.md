# 来源、版本与边界

- [lunar-javascript 1.7.8](https://github.com/6tail/lunar-javascript/releases/tag/v1.7.8)，MIT；历法、四柱、节气和十神，不做西方星盘或心理测量。
- [ichingshifa 3.1.9](https://pypi.org/project/ichingshifa/3.1.9/)，MIT；实际调用 Iching.bookgua 和 Iching.mget_bookgua_details。只使用固定来源的包，不载入用户提供的 Python 序列化数据。三钱六爻是独立规则。
- 塔罗名称与结构参考 [A. E. Waite](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot)。中文名是编辑命名；反思提示与 SVG 为项目原创示意，不复制牌图。
- [IPIP Mini-IPIP 计分键](https://ipip.ori.org/MiniIPIPKey.htm) 与 [公有领域说明](https://ipip.ori.org/newPermission.htm)。英文题与方向来自计分键，中文意译和聊天推断未验证，不是 MBTI。
- [Temporal polyfill 0.5.1](https://github.com/js-temporal/temporal-polyfill)、运行时 ICU/IANA、[Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy)。独立核对包括 IANA、USNO 及 Swiss/Moshier；后者不随包交付。
- 动效只借 [Holo Card Studio](https://github.com/EverettFish/holo-card-studio) 分层概念和 PRD 的弱箔光方向。不运行其 Blender/Three.js 流程，也不复用参考帖的画面。

## 发布与许可范围

项目代码及原创文档、示意 SVG 采用根目录的 MIT 许可证。IPIP 英文题项及官方计分键为公有领域资料，出处如上；本项目不主张对其新增版权。塔罗传统牌名、花色和牌序，以及周易传统卦名、卦序和阴阳爻数据用于识别，不包含现代译本、图解原文或第三方图像。其余演示内容均为合成样例。不打包第三方软件、商业牌图、外部视觉参考、引擎二进制或数据集；依赖经各自软件仓库安装，各自许可不变。
